# AtlasLootClassic_TBC_Deehorlok

An [AtlasLootClassic](https://www.curseforge.com/wow/addons/atlaslootclassic) submodule that adds an **Affliction Warlock BIS list for TBC Phase 3 (BT / Hyjal)** — curated for Deehorlok.

Sourced from the [Wowhead Affliction Warlock BT/Hyjal Phase 3 BIS guide](https://www.wowhead.com/tbc/guide/affliction-warlock-dps-bt-hyjal-phase-3-best-in-slot-gear-burning-crusade).

## Install

1. Install [AtlasLootClassic](https://www.curseforge.com/wow/addons/atlaslootclassic).
2. Drop this folder into `Interface\AddOns\AtlasLootClassic_TBC_Deehorlok`.
3. In game, open AtlasLoot → Sets → look for **Warlock Affliction BiS (Phase 3) — Deehorlok**.
4. (Optional) Install [AtlasBIStooltips](https://www.curseforge.com/wow/addons/atlas-bis-tooltip) to see BIS annotations in item tooltips.

## Requires

- TBC Classic 2.5.6 (`Interface: 20506`)
- AtlasLootClassic
